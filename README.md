# BreakTaboo 🏆

> This was a "phygital" (physical + digital) game built for a hackathon. Its purpose is to break the silence around sexual health for Morocco's youth.

## 💡 The Concept

We didn't just build an app; we designed an experience. BreakTaboo works by linking physical debate cards to a dynamic web application. 

The app is the digital guide: it's the timer, the arbitrator, the XP tracker, and the success-unlocker. We turned a sensitive, taboo subject into an engaging, gamified, and safe space to learn.

## 🛠️ Technology Used

* **HTML5**
* **CSS3**
* **JavaScript (JS)**

## 🏆 Hackathon Project

This project was built for the **3rd edition of the Digi-hackathon (Mobile Health)** at FST Tangier. 

Our team's solution, "BreakTaboo," was created to address the hackathon's central theme: "Sexual and reproductive health of adolescents and young people."
